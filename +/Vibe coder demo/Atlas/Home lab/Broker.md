# Broker
**Means:** The server that receives [[MQTT]] messages and passes them on to everything subscribed. It is Mosquitto on the Pi, shared by both projects. See [[Set up MQTT broker on the Pi]].

## Watch out
If the broker is down, nothing fails loudly. The sensors just go quiet.
