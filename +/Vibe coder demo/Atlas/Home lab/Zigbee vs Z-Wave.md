# Zigbee vs Z-Wave
*Decision: Zigbee.*
| | Zigbee | Z-Wave |
|---|---|---|
| Cost | cheap | pricey |
| Range | needs mains-powered routers | better through walls |
| Variety | huge | smaller |

Mesh problems on Zigbee are usually fixed with one more mains-powered device. See [[Replace flaky Zigbee bulbs]].
