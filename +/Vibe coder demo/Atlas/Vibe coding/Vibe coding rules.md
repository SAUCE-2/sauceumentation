# Vibe coding rules
*Rules I wrote after the AI rewrote half the app to fix a typo.*
1. Commit before every prompt. Reverting beats arguing.
2. Plan first, code second.
3. One feature per session. Start a new chat after that.
4. Read the diff. All of it. Even the boring files.
5. Secrets never go in the chat. Use `.env` and a placeholder.
6. If it fails the same way twice, stop and read the error myself.
