# Prompt recipes
*Prompts that earned a place here.*
## Start a feature
> Read the repo first. Propose a plan in 5 bullets. Don't write code until I say go.

## Fix a bug
> Here's the error and the file. Explain the cause before changing anything. Smallest fix please.

## Dinner from leftovers ([[Pantry Pal]])
> Here are items that expire soon: ... Give 3 dinners, 30 min max, hob and oven only. One line each.

## Snark ([[Fridge Gossip]])
> You are a judgmental fridge. The door opened N times since 6pm. One short sentence, dry, no emojis.
