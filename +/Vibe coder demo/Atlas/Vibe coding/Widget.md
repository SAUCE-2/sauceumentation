# Widget
**Means:** A small, glanceable tile that shows live info without opening the full app.

## In [[Plant Parent]]
An iOS home-screen widget built with WidgetKit. It refreshes on a timeline that the system controls, so it is never truly live. See [[Watering streak widget]].

## In [[Casa]]
A card on a [[Home Assistant]] dashboard. It updates the moment a sensor changes. See [[Energy dashboard]].

## Watch out
Asking an AI for "a widget" without saying which kind gets you the wrong framework entirely.
